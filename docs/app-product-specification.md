# 📱 앱 기획서 - 집중해 햄콩!

## 1. 개요
- 앱 이름: 집중해 햄콩!
- 플랫폼: Android (1차 출시)
- 타겟: 10~20대 여성 (귀여운 UI 선호)
- 핵심 컨셉:
  - 초미니멀 집중 타이머
  - 귀여운 햄스터 캐릭터 "햄콩" 기반 UX
  - 감정 기반 피드백
  - "생각 없이 바로 시작하는 집중 앱"

---

## 2. 핵심 기능 (MVP)

### 2.1 타이머 기능
- 사용자는 시간을 선택 후 타이머 시작
- 기본 옵션:
  - 5분 / 10분 / 25분
- 커스텀 시간 입력 (선택)

### 2.2 타이머 상태
- idle (대기)
- running (진행 중)
- success (완료)
- fail (중도 종료)

---

## 3. 사용자 흐름

1. 메인 화면 진입
2. 시간 선택
3. 시작 버튼 클릭
4. 응원 메시지 표시
5. 타이머 진행 화면
6. 종료 (성공 or 중도 종료)
7. 결과 메시지 표시
8. 종료 시 전면 광고

---

## 4. 화면 구성

## 4.1 메인 화면
- 구성 요소:
  - 앱 타이틀
  - 햄스터 캐릭터 (idle 상태)
  - 시간 선택 버튼 (5 / 10 / 25 / custom)
  - 시작 버튼

---

## 4.2 타이머 진행 화면
- 구성 요소:
  - 남은 시간 (큰 숫자)
  - 원형 프로그레스 바 (뽀모도로 스타일)
  - 햄스터 캐릭터 (집중 상태)
  - 종료 버튼

---

## 4.3 결과 화면

### 성공 시
- 메시지:
  - "{N}분 집중 성공!! 고생했어 🎉"
- 햄스터 상태:
  - 기쁨 / 점프

### 중도 종료 시
- 메시지:
  - "지금 {N}분 버텼어, 여기서 끝낼거야?"
- 햄스터 상태:
  - 아쉬움 / 슬픔

---

## 5. UX 메시지 정의

### 시작 시
- "화이팅! {N}분 후에 만나자 💪"

### 진행 중
- 별도 메시지 없음 (집중 유지)

### 중도 종료 시
- "지금 {N}분 버텼어, 여기서 끝낼거야?"

### 성공 시
- "{N}분 집중 성공!! 고생했어 🎉"

## 6. 캐릭터 (햄스터)

### 상태 정의
- idle (기본)
- focusing (집중 중)
- success (기쁨)
- fail (슬픔)

### 디자인 방향
- 파스텔톤
- 단순한 형태 (원형 기반)
- 표정 변화 중심
- 과한 애니메이션 금지

- 정책:
  - 중도 종료 시 광고 노출 금지
